# Folia for iPhone

非官方 Folia iOS 移植，最低 iOS 17，介面使用臺灣繁體中文。

0.3.0 移植電腦版商籟（Sonnet）文字動畫引擎，加入沉浸模式，以及 Folia 內的 YouTube 影片播放與同步歌詞匹配。YouTube 官方播放器保持可見，離開播放畫面或切到背景會暫停。Spotify 目前仍為曲庫與外部播放入口。

- [Google／YouTube 維護者設定](ios/docs/Google-YouTube-maintainer.zh-TW.md)
