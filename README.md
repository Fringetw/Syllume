# Syllume

Syllume 是 iPhone 音樂播放器，從 [Folia Major](https://github.com/chthollyphile/folia-major) 移植商籟和繪光歌詞動畫。支援 iOS 17 以上，介面使用臺灣繁體中文。

- 播放本機和 Navidrome 音訊，支援鎖定畫面控制與背景播放。
- 同步 YouTube 歌單與喜歡的影片，在歌單、迷你播放器和封面頁顯示圖片。點歌時比對可用的同版本音源，也可附加已有的音檔。
- 內建 [OpenCC 繁體字幕](https://github.com/Fringetw/folia-traditional-chinese)，可離線簡轉繁、搜尋同步歌詞和匯入字幕。
- 在「設定 → 開發者診斷」查看音源、字幕、動畫和裝置的測試結果，匯出 JSON 或純文字。
